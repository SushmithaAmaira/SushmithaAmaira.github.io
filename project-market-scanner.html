Hourly Market Scanner

A Streamlit web app that scans hourly OHLC (Open, High, Low, Close) data for a custom watchlist of NSE stocks. Auto-runs every hour during market hours, shows historical hourly data for any day in the past week, and supports full watchlist management.

Data Interval

Auto Scan

History
7 days lookback
Overview

What I Built

A background hourly market scanner that automatically fetches OHLC data for a custom watchlist of NSE stocks every hour during market hours. The Streamlit dashboard has 4 tabs — live OHLC view, historical candlestick charts, watchlist management, and a scan schedule log.

The scanner runs as a background daemon thread using the schedule library, meaning it continues scanning even while you navigate between tabs. All scan logs are saved to JSON for reference.

Kite Connect APIs Used

Free Tier APIs Only

APIUsed For
kite.generate_session()OAuth login — exchange request_token for access_token
kite.profile()Show logged-in user name in sidebar
kite.holdings()Auto-import your Zerodha stocks into the watchlist

Note: ltp() and historical data are NOT used — those require paid plan. All price data comes from yfinance which is completely free.

Process

How I Built It

1
Decided what to build
Hourly OHLC scanner with auto-refresh, 7-day history, and full watchlist management — using only free data sources.
2
Chose data sources
yfinance for free 1h interval OHLC data (up to 7 days), Kite Connect free tier for profile, holdings and symbol validation, and the schedule library for background hourly jobs.
3
Built 5 core files
auth.py for Kite OAuth, watchlist.py for JSON-based CRUD, scanner.py for yfinance with IST timezone conversion, scheduler.py for background daemon thread, and app.py for the full Streamlit UI.
4
Fixed st.stop() bug
st.stop() inside the Live OHLC tab was stopping ALL tabs from rendering when the watchlist was empty. Fixed by removing st.stop() and using an info message instead.
5
Fixed widget key clash
Widget key "hist_sym" clashed with session state key "hist_sym" — Streamlit doesn't allow this. Fixed by renaming widget keys to wgt_hist_sym and storing results under hist_result_sym.

Takeaways

What I Learned

  • Background threads in Streamlit — using Python's threading module to run hourly scans while the UI stays responsive
  • OHLC data — understanding Open, High, Low, Close and what each tells you about price action within a time period
  • yfinance intervals — 1h interval data is available for the last 7 days for all NSE stocks
  • IST timezone handling — NSE market data comes in UTC, must convert to IST for correct display
  • Streamlit session state — widget keys and session state keys cannot overlap — fixed by using separate naming conventions
  • JSON as a lightweight database — perfect for simple watchlists and scan logs without needing SQLite or a full database
