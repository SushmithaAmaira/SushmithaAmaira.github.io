Overview

What I Built

A SIP backtest simulator for any NSE stock, index or Indian mutual fund. Enter any stock symbol or fund name, set a monthly SIP amount and start date, and the app calculates exactly what your investment would be worth today — with XIRR, a Nifty 50 benchmark comparison, month-wise breakdown table, and interactive Plotly charts.

The app uses a smart hybrid architecture — yfinance for all historical stock/index data, MFAPI for mutual fund NAV history, and Kite Connect optionally for live prices and your actual Zerodha MF holdings.

Process

How I Built It

1
Decided what to build
SIP backtest simulator showing total invested, current value, XIRR and Nifty 50 comparison — using only free data sources.
2
Discovered Kite Connect limitations
Kite Connect's historical data endpoint requires a paid plan (₹2,000/month) and daily OAuth re-login — not suitable as the primary data source.
3
Switched to yfinance
yfinance is 100% free, needs no API key, and has data going back to the 1990s for all NSE stocks (.NS), BSE stocks (.BO) and indices (^NSEI for Nifty 50).
4
Built hybrid architecture
yfinance handles all historical data, Kite Connect provides live real-time price if the user is logged in, with graceful fallback to yfinance's last close if not.
5
Added Mutual Funds support
Built a new hybrid for mutual funds — MFAPI for full historical NAV data (sourced from AMFI, the official regulator) and Kite MF API for current NAV and user's actual holdings.
6
Fixed bugs and theme issues
Fixed yf.fast_info reliability issues for Indian stocks, expanded symbol map with 15+ index aliases, and fixed CSS dark theme override by replacing hardcoded colours with Streamlit CSS variables.
Takeaways

What I Learned

  • XIRR — the correct way to measure investment returns when cash flows happen at irregular intervals (like monthly SIPs)
  • Hybrid API architecture — combining multiple free data sources with graceful fallbacks when optional paid sources are unavailable
  • MFAPI + AMFI — India's official mutual fund NAV data is publicly available for free via AMFI, accessible through MFAPI
  • yfinance for Indian markets — NSE stocks need .NS suffix, BSE need .BO, and indices use ^ prefix (^NSEI for Nifty 50)
  • Benchmark comparison — always compare investment returns against an index to know if the stock actually added value
  • Streamlit CSS variables — use var(--background-color) instead of hardcoded hex values for proper light/dark theme support
