🦆 Portfolio Analytics Engine

High-performance analytical queries using DuckDB to filter, sort and analyse large CSV datasets. Features live USD→INR conversion, Skincare product filtering, and in-stock analysis on million-row files — all from the terminal.

Overview

What I Built

This project uses DuckDB — an in-process SQL analytics database — to query massive CSV files directly without loading them into memory. I wrote SQL queries to filter products by category (Skincare), availability (in-stock), and converted all prices from USD to INR using the live exchange rate.

DuckDB's ability to query .csv files directly with standard SQL made this extremely fast — querying a 1-million row file takes under a second.

Process

How I Created It

1
Loaded the CSV into DuckDB
Used DuckDB's direct file querying — no import needed, just reference the file path in SQL.
2
Fetched live USD→INR rate
Used a web search to get the real-time exchange rate (₹93.09 per USD on April 10, 2026) and hardcoded it into the query.
3
Wrote the filtering query
Filtered by Category = 'Skincare' AND Availability = 'in_stock', then multiplied price by the exchange rate and used ROUND() to remove decimals.
4
Exported results to CSV
Used DuckDB's COPY ... TO statement to export the filtered results directly to a new CSV file.
Code

Key Code Snippets

analytics_query.sqlSQL
-- Filter Skincare products that are in stock
-- Convert price from USD to INR (rate: 1 USD = 93.09 INR)
SELECT
    Index,
    Name,
    Description,
    Brand,
    Category,
    ROUND(Price * 93.09) AS Price,
    'INR'           AS Currency,
    Stock,
    Availability
FROM 'products-1000000.csv'
WHERE Category     = 'Skincare'
  AND Availability = 'in_stock';
export_results.sqlSQL
-- Export filtered results to a new CSV file
COPY (
    SELECT
        Index, Name, Description, Brand, Category,
        ROUND(Price * 93.09) AS Price,
        'INR' AS Currency,
        Stock, Availability
    FROM 'products-1000000.csv'
    WHERE Category = 'Skincare'
      AND Availability = 'in_stock'
) TO 'Skincare_InStock_INR.csv' (HEADER, DELIMITER ',');

Takeaways

What I Learned

  • DuckDB can query CSV files directly without importing — extremely fast even on 1M+ rows
  • ROUND() eliminates floating-point precision issues in currency calculations
  • COPY ... TO makes exporting filtered results to CSV a one-liner
  • SQL WHERE + AND chaining is the cleanest way to apply multiple filters
  • Live exchange rates can be fetched and hardcoded for reproducible analysis
