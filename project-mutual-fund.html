📊 Mutual Fund Analytics Dashboard

A complete mutual fund analytics dashboard showing my entire investment journey in the Zerodha Nifty LargeMidcap 250 Index Fund — with live data, NAV history, and every single transaction displayed beautifully using Streamlit.

Overview

What I Built

A Streamlit web dashboard with 6 interactive sections that combines three different data sources — Zerodha's Kite Connect API for live holdings, MFAPI for full NAV history, and my CAMS statement for complete transaction history. Everything is tied together in Python and displayed with Plotly charts.

Dashboard

6 Sections Inside the Dashboard

Section 01
Live Portfolio Summary
9 metric cards showing total purchased, redeemed, net invested, current value, P&L, units, NAV and transaction counts
Section 02
Complete Transaction Table
Every transaction since inception — colour coded green for purchases and red for redemptions
Section 03
Unit Balance Timeline Chart
Interactive line chart showing how units grew and fell over time with triangle markers on each transaction
Section 04
Cumulative Investment Chart
Shows how much was invested vs redeemed over time on a single interactive chart
Section 05
NAV History + Transactions
Full NAV chart from inception with buy/sell points marked directly on it — very impressive visually
Section 06
Fund Information
All fund details — expense ratio, benchmark, inception date, risk level and more

Process

How I Built It

1
Discovered Kite Connect MF API
Found that kite.mf_holdings(), kite.mf_sips() and kite.mf_orders() are all free with Kite Connect Personal API.
2
Fetched live MF data
Ran Python commands to see actual live holdings — 6,155.721 units of Zerodha Nifty LargeMidcap 250.
3
Discovered the 7-day limit
Found that mf_orders() only gives the last 7 days — not full history. Needed another solution.
4
Found MFAPI solution
Discovered mfapi.in — a completely free public API that gives full NAV history since fund inception (Nov 2023). No authentication needed.
5
Got CAMS Statement
Went to camsonline.com → MF Investors → CAS-CAMS+KFintech → Downloaded detailed statement → Got complete transaction history.
6
Built the dashboard
Combined all 3 data sources into one Streamlit app with 6 sections — live data, transaction history, and 4 interactive Plotly charts.
7
Fixed compatibility & ran it
Fixed pandas 3.0 compatibility issue (applymap → map), then ran streamlit run app.py — full dashboard live in browser with real data!

Takeaways

What I Learned

  • How to combine 3 different data sources — Kite Connect, MFAPI, and CAMS — into one unified dashboard
  • MFAPI gives free historical NAV data for all Indian mutual funds — no authentication needed
  • Using @st.cache_data with different TTLs for different data types (5 min for live data, 1 hour for NAV history)
  • Overlaying transaction markers directly on a NAV history chart using Plotly
  • Real financial concepts — NAV, units, redemption, CAMS, ISIN
  • Pandas cumulative calculations for running balances and investment totals
