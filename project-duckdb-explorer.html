Overview

What I Did

This project is my getting started journey with DuckDB — a powerful in-process SQL analytics engine that can query CSV files directly without loading them into memory. I downloaded real sample datasets with 1,00,000 and 10,00,000+ rows and used vibe coding with Claude AI to write SQL queries, filter data, convert currencies and export results — all from the terminal.

What surprised me most was how fast DuckDB is — querying a 10 lakh row CSV file takes under a second. No database setup, no server, just Python and SQL.

💬 How I built this: I described what I wanted to do in plain English to Claude AI — "filter this CSV for only Skincare products that are in stock and convert the price to INR" — and Claude helped me write the exact DuckDB SQL query. This is vibe coding — using AI as your coding partner to get real work done without needing to memorise syntax.

Code

Key SQL Queries

country_filter.py — Interactive CLI toolPython
import duckdb

FILE = r"C:\Users\nithi\Downloads\customers-100000.csv"

print("=== Customer Data Filter === (type 'exit' to quit)")

while True:
    country = input("Enter country name: ").strip()
    if country.lower() == 'exit': break

    result = duckdb.query(f"""
        SELECT * FROM '{FILE}'
        WHERE Country = '{country}'
    """).df()

    print(f"Found {len(result)} records for '{country}'")
    print(result.to_string(index=False))
analytics_query.sql — Filter + currency conversionSQL
-- Filter Skincare products in stock, convert USD → INR
SELECT
    Index, Name, Brand, Category,
    ROUND(Price * 93.09) AS Price,
    'INR'               AS Currency,
    Availability
FROM 'products-1000000.csv'
WHERE Category     = 'Skincare'
  AND Availability = 'in_stock';
export.sql — Export results to new CSVSQL
-- Export filtered results directly to a new CSV file
COPY (
    SELECT
        Index, Name, Brand, Category,
        ROUND(Price * 93.09) AS Price,
        'INR' AS Currency,
        Availability
    FROM 'products-1000000.csv'
    WHERE Category = 'Skincare'
      AND Availability = 'in_stock'
) TO 'Skincare_InStock_INR.csv' (HEADER, DELIMITER ',');
