Overview

What I Built

This project is a comprehensive deep-dive into Zerodha's Kite Connect API using the official pykiteconnect Python library. I documented every function, method, and callback available in the v4 SDK — turning scattered documentation into a clean, printable PDF reference.

The study suite covers two main components of the SDK: KiteConnect (REST API for orders, portfolio, instruments) and KiteTicker (WebSocket for live streaming market data).

Code

Key Code Snippets

kite_ticker_basic.py Python 
from kiteconnect import KiteTicker

# Initialise KiteTicker with your API key and access token
kws = KiteTicker("your_api_key", "your_access_token")

def on_ticks(ws, ticks):
    # Runs every time new price data arrives
    for tick in ticks:
        print(f"Token: {tick['instrument_token']} | LTP: {tick['last_price']}")

def on_connect(ws, response):
    # Subscribe to NIFTY 50 and RELIANCE on connection
    ws.subscribe([256265, 738561])
    ws.set_mode(ws.MODE_FULL, [256265, 738561])

def on_close(ws, code, reason):
    print(f"Connection closed: {code} - {reason}")

# Assign callbacks
kws.on_ticks = on_ticks
kws.on_connect = on_connect
kws.on_close = on_close

# Enable auto-reconnect (max 50 retries, 60s max delay)
kws.enable_reconnect(reconnect_max_tries=50)

# Start the WebSocket connection (blocking)
kws.connect()
kite_place_order.py Python 
from kiteconnect import KiteConnect

kite = KiteConnect(api_key="your_api_key")
kite.set_access_token("your_access_token")

# Place a market buy order for INFY on NSE
order_id = kite.place_order(
    tradingsymbol="INFY",
    exchange=kite.EXCHANGE_NSE,
    transaction_type=kite.TRANSACTION_TYPE_BUY,
    quantity=1,
    order_type=kite.ORDER_TYPE_MARKET,
    product=kite.PRODUCT_CNC
)

print(f"Order placed! ID: {order_id}")

# Fetch current holdings
holdings = kite.holdings()
for h in holdings:
    print(f"{h['tradingsymbol']}: {h['quantity']} @ avg ₹{h['average_price']:.2f}")
