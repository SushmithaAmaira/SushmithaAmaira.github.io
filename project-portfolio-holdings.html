Overview

What I Built

A personal portfolio dashboard that replaces the default Zerodha app view with a custom analytics interface. It connects to Zerodha via the Kite Connect API, fetches live holdings data, calculates P&L and return percentages using Pandas, and visualises everything through interactive Plotly charts — all wrapped in a Streamlit web app.

The dashboard includes sector allocation (Banking, IT, EV etc.), per-stock P&L bar charts, return percentage analysis, metric summary cards, a colour-coded holdings table, and a refresh button — all built with pure Python, no HTML or JavaScript needed.

Deep Dive

What Happens When You Run the App

01
Streamlit starts a web server on your laptop
02
Browser opens localhost:8501
03
get_kite() runs — creates a KiteConnect object with your API key and access token
04
fetch_holdings(kite) runs — sends HTTP GET request to Zerodha's servers
05
Zerodha validates your access token and returns your holdings as JSON
06
Pandas converts JSON → DataFrame, calculates Invested, Current Value, Return %
07
Sector map adds a "Sector" column to each stock for the pie chart
08
Plotly creates pie chart and bar charts from the DataFrame
09
Streamlit renders everything as a web app in your browser
10
Your beautiful portfolio dashboard is live! 🎉

Takeaways

What I Learned

  • REST API integration — Kite Connect communicates via HTTP GET requests, just like a browser loading a webpage
  • Access token authentication — the two-step flow: request_token → access_token, used by Google, Twitter, GitHub and every major API
  • Pandas DataFrames — converting raw JSON API data into structured tables with calculated columns
  • Plotly interactive charts — px.pie() for donut charts, px.bar() for horizontal and vertical bar charts, all hoverable and zoomable
  • Streamlit web apps — st.metric(), st.columns(), st.plotly_chart(), st.dataframe() — full web app in pure Python
  • Data caching — @st.cache_data(ttl=300) stores data in memory for 5 minutes, a technique used in production systems at every major tech company
