🗂️ Country Data Filter CLI

An interactive terminal tool using DuckDB that prompts for a country name and dynamically filters a 100,000-row customer dataset on the fly — no file modification needed, pure SQL query speed.

Language
Python + DuckDB
Dataset
100,000 rows CSV
Interface

Overview

What I Built

A Python CLI tool that connects to a 100,000-row customer CSV using DuckDB and prompts the user to enter a country name. It then runs a parameterised SQL query and displays all matching customer records instantly in the terminal — no pandas, no manual file edits, just raw SQL speed.

Process

How I Created It

1
Uploaded and inspected the CSV
Loaded a 100K row customers CSV file and previewed the first 5 rows to understand column names and structure.
2
Wrote a parameterised DuckDB query
Used Python's input() to prompt for a country, then injected it into a DuckDB SQL query using f-strings for dynamic filtering.
3
Displayed results in terminal
Used DuckDB's .df() method to return results as a pandas DataFrame and printed them clearly in the terminal.
4
Added loop for re-querying
Wrapped the query in a while loop so users can keep filtering for different countries without restarting the script.
Code

Key Code Snippet

country_filter.pyPython
import duckdb

# Path to your CSV file
FILE_PATH = r"C:\Users\nithi\Downloads\customers-100000.csv"

print("=== Customer Data Filter ===")
print("Type 'exit' to quit.\n")

while True:
    country = input("Enter country name: ").strip()

    if country.lower() == 'exit':
        print("Goodbye!")
        break

    query = f"""
        SELECT *
        FROM '{FILE_PATH}'
        WHERE Country = '{country}'
    """

    result = duckdb.query(query).df()

    if len(result) == 0:
        print(f"No results found for '{country}'. Try again.\n")
    else:
        print(f"\nFound {len(result)} records for '{country}':")
        print(result.to_string(index=False))
        print("\n")

Takeaways

What I Learned

  • DuckDB can be used from Python with just import duckdb — no server setup needed
  • Parameterised queries with f-strings allow dynamic, user-driven filtering
  • The .df() method converts DuckDB results to a pandas DataFrame instantly
  • A simple while loop turns a single query into a powerful interactive CLI tool
  • CSV files with 100K+ rows query in milliseconds with DuckDB
