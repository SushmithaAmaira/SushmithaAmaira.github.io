Overview

What I Built

A full-stack order management system using Zerodha's Kite Connect Personal API and Streamlit. The dashboard supports market and limit orders, CNC and MIS product types, regular and After Market Orders (AMO) — all using only the free tier of Kite Connect API.

Most impressively — I successfully placed a real LIMIT order for IOB stock and saw it execute with COMPLETE status in the order history. This is a live, functional trading tool.

Takeaways

What I Learned

  • LIMIT vs MARKET orders — LIMIT executes only at your specified price; MARKET executes at whatever price is available
  • CNC vs MIS — CNC is for delivery (hold as long as you want); MIS is intraday only (auto-closes by 3:20 PM)
  • AMO orders — After Market Orders placed after 3:30 PM execute next morning at 9:15 AM
  • SEBI IP Whitelisting — As of April 2026, all API-based orders must come from a registered IP address
  • Kite Connect Order Flow — How an order travels from dashboard → Zerodha servers → NSE/BSE exchange → execution
  • Safety features — Built confirmation checkbox and max order value limit in config.py to prevent accidental large orders
